# Navegador

Navegador próprio em cima do Chromium, com o visual do Dia: menu lateral, vários perfis e containers. Roda no Linux (Arch).

- Como funciona: [docs/ARQUITETURA.md](docs/ARQUITETURA.md)
- Compilar: `~/Work/navegador-chromium/sync.sh` (baixa o Chromium da versão em `CHROMIUM_VERSION`), `tools/fonte.sh` (aplica as nossas mudanças) e `tools/compilar.sh`.
